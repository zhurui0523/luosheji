# AI Creative Director Plugin

This is a complete XiaoLuo plugin package. It owns its manifest, runtime entry, skill definition, and documentation under one folder.

Package contract:

- `manifest.json`: portable extension metadata for import, install, enable, disable, and uninstall flows.
- `manifest.ts`: typed runtime manifest used by the local application bundle.
- `skill.ts`: plugin capability implementation.
- `index.ts`: package entry.
