# 🪐 XiaoLuo AI Intent OS - UI/UX 视觉与交互风格指南 (UI Style Guide)

本指南旨在规范 **XiaoLuo AI Intent OS** 交互画布、卡片、DAG 节点、贝塞尔连线及中央控制台的视觉美学、过渡动效和交互手势设计。所有内置与第三方插件贡献的 UI 组件，必须严格遵守本规范，保障极致专业、克制的工业级创作体验。

---

## 🎨 视觉调色盘 (The Space-Industrial Theme)

为了贯彻**克制开发、低碳美学、高易读性**的未来操作系统质感，系统全局采用**太空工业深色主题（Space-Industrial Dark Theme）**。

### 1. 基础背景层级
*   **画布大底 (Canvas Base)**: `#09090b` (Tailwind `zinc-950`)。平整、克制。
*   **网格背景 (Grid Background)**: 运用微弱、高对比的十字交叉网格或虚线圆点，颜色深度为 `#18181b`（Tailwind `zinc-900`），保证视差层叠感。
*   **卡片底色 (Card Base)**: 透明度在 `90%` 至 `95%` 的毛玻璃质感，背景采用 `#18181b` 或 `#0f172a`（深邃蓝），配以高对比边框。

### 2. 状态高亮与辅助色
*   **主色/激活态 (Primary/Active)**: `#6366f1` (Tailwind `indigo-500`) 或 `#06b6d4` (Tailwind `cyan-500`)，用于流光连线和关键高亮。
*   **成功/完成 (Completed)**: `#10b981` (Tailwind `emerald-500`)，展现资产成功渲染。
*   **故障/阻断 (Failed/Error)**: `#ef4444` (Tailwind `red-500`)，警示报错。
*   **未激活/静默 (Muted)**: `#3f3f46` (Tailwind `zinc-700`)，辅以低对比文字颜色 `#a1a1aa` (Tailwind `zinc-400`)。

## ✍️ 极致印刷体排版 (Typography)

*   **常规系统文字与标签 (UI Text & Controls)**:
    *   字体系列一律使用 **Inter** 或 **System UI** 无衬线字体。
    *   字号保持紧凑和专业密度（常用 `sm`、`xs`），绝不显露臃肿。
*   **技术参数、日志与数据 (Metrics & Logs)**:
    *   必须使用 **JetBrains Mono** 或 **Fira Code** 等等宽字体。
    *   配合 `tracking-wider` 展现纯正、工业级的技术颗粒感。

## ⚙️ 画布节点与交互卡片规范 (Canvas Cards & Edit-on-Canvas Spec)

> 【🚨 核心改进方案】针对用户对“在画布上无法直接修改节点属性参数”的关切，以下提供在画布工作台（HistoryCard）中进行**原地高保真编辑与控制**的交互范式：

```
+-------------------------------------------------------------+
| ● 节点 2 (Script Node)                         [ 🛠️ 运行中 ] |
+-------------------------------------------------------------+
|  [ 标题/名称 ]                                               |
|  [ 节点 2                             ] <── 支持原地修改标题  |
|                                                             |
|  [ 执行模型/算力 ]                                           |
|  [ Hermes / deepseek-v4-pro         ▼ ] <── 支持下拉切换模型  |
|                                                             |
|  [ 技能/指令集 ]                                            |
|  [ 技能, 按 Enter 添加                ▼ ] <── 支持动态插拔技能  |
|                                                             |
|  [ 意图微调/描述 ]                                           |
|  [ 描述这个 Agent 要做什么...          ] <── 原地自由增删修改  |
|  [                                   ]                      |
|                                                             |
|  [ 📂 输入插口 ] <─── 连线汇入点                输出插口 ───>  |
|                                                             |
|  + (添加下级节点按钮)                                         |
+-------------------------------------------------------------+
```

### 1. 原地编辑交互规范 (Canvas Inline Editing)
1.  **卡片不被画布捕获拦截**: 任何卡片内部的表单元素（`input`, `textarea`, `select`）必须配置 `onPointerDown={e => e.stopPropagation()}` 与 `.no-canvas-intercept` 样式。这样在用户点击编辑框或拖拽输入条文本时，画布不会跟着漂移、缩放（Zoom/Pan）。
2.  **即时保存与全局同步**: 任何原地修改（如在 `textarea` 中重置 Prompt 或在 `select` 中切换了模型）必须在 `onChange` 时立即分发 `update-node-config` 广播事件，并直接同步写入 `localStorage` 与内存中的 `activeCanvas.history`，保证“所改即所见，所见即所存”。
3.  **模型参数自愈映射**: 切换模型（如从 `Hermes` 切换到 `deepseek-v4-pro`）时，卡片底部的插口数量和入参结构应自动做出安全检测并弹性重构。

### 2. 状态与加载指示 (States Visuals)
*   **Pending 状态**: 灰色虚线边框，内容轻度毛玻璃模糊，显示 `+` 添加后置流程。
*   **Running 状态**: 边框带有循环流动的亮蓝色跑马灯光效（`animate-pulse`），标题显示精确的百分比进度和 Agent 心跳文字。
*   **Completed 状态**: 绿色实线边框，左上角显示打勾徽标，展示最终渲染产物（如精美原画或可播放视频），支持一键全屏、下载或导出。

## ➰ 连线算法与流光动效 (Flow Connections)

连线不仅是视觉装饰，更是 DAG 拓扑关系和数据穿透流向（Data Flow）的可视化实体：

1.  **贝塞尔曲线平滑绘制**:
    *   连线必须使用 **三阶贝塞尔曲线 (Cubic Bezier Curves)**，计算公式如下：
        $$P(t) = (1-t)^3P_0 + 3(1-t)^2tP_1 + 3(1-t)t^2P_2 + t^3P_3$$
    *   起点 $P_0$ 为上游卡片的输出插口（Right Socket），终点 $P_3$ 为下游卡片的输入插口（Left Socket），控制点 $P_1$ 和 $P_2$ 沿 X 轴对称延展，在卡片位置变动时自适应重绘。
2.  **动态状态流光 (Flow Animations)**:
    *   **静默态**: 呈现为 `#3f3f46` 虚线。
    *   **传输激活态**: 呈现为高亮 `#06b6d4`。连线内部含有**流光动画**（利用 SVG 的 `stroke-dasharray` 与 `stroke-dashoffset` CSS 动画，形成向后方输送数据包的物理律动）。
    *   **连线类型约束**: 严禁将视频输出端插口与脚本输入端插口反向错连。在鼠标拖拽悬浮于不匹配插口上方时，该插口闪烁猩红色微光并进行磁力推开，杜绝违规 DAG 的建立。

## 💫 物理过渡动效 (Micro-Animations)

*   **极速响应原则**: 所有的过渡时间限制在 `150ms` 至 `250ms` 内，避免冗长卡顿：
    *   卡片进入/退出：`ease-out` 的轻微垂直向上飞入或淡入，缩放比例由 `95%` 弹至 `100%`。
    *   按钮 Hover：背景色与投影的高斯模糊同步缩放（`scale-105 transition-all duration-200`）。
*   **严禁无意义装饰**: 不要挂载会阻碍大模型运行的重载网页动画特效。系统的所有动效，都必须伴随着状态变更、连线导向或新资产的诞生的功能性意义。
